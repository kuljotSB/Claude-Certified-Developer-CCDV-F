# Marketing Review Skill

Use this Skill whenever the user asks you to:

- Review marketing copy
- Improve LinkedIn posts
- Generate promotional announcements
- Rewrite advertisements
- Create product launch content

## Instructions

When invoked:

1. Read **brand-guidelines.md**
2. Read **marketing-checklist.md**
3. If the user requests a LinkedIn post, also read **linkedin-template.md**
4. Improve the marketing content.
5. Explain what improvements were made.

Always follow the branding guidelines before producing your response.
