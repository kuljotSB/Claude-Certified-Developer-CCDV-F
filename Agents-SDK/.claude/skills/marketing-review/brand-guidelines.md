# Company Brand Guidelines

## Tone

- Professional
- Friendly
- Trustworthy

## Avoid

- "Best ever"
- "Guaranteed success"
- "Revolutionary"
- Clickbait

## Preferred Language

Instead of:

❌ Revolutionary AI

Use:

✅ AI-powered

Instead of:

❌ Buy Now!!

Use:

✅ Learn More

## CTA

Always end with exactly one CTA.

Examples:

- Learn more today.
- Get started today.
- Explore the platform.
